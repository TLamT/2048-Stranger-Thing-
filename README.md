
# 2048 Stranger-Thing-
Introduction
This is a classic 2048 number puzzle game built using pure HTML, CSS, and JavaScript. Players can control the tiles using the arrow keys to slide left, right, up, or down, with the goal of reaching 2048 or higher scores. The game dynamically switches background images based on the current score range, enhanced with smooth fade-in and fade-out transition animations for a seamless visual experience.

Features
Intuitive Controls: Use arrow keys on the keyboard to move tiles.
Dynamic Background: Automatically change background images based on the highest score, with fade transition effects.
Real-time Score Display: Continuously update and show the highest score.
Game Over Notification: Display a game over message when no more moves are possible.
Responsive Design: Adapts to different screen sizes for better usability.
Content Structure
index.html: Main HTML file
index.js: Game logic and background transition control
How to Play
Download or clone the project folder to your computer.
Open index.html in your web browser.
Use the arrow keys to slide and merge tiles.
Click the "Start" button to restart the game.
