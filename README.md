# 2048: Stranger Things Edition

A logic-based puzzle game with a custom Stranger Things theme.

👉 [Play the Game Here](https://tlamt.github.io/2048-Stranger-Thing-/)

---

## Features

- **Classic 2048 gameplay** — slide tiles, merge matching numbers, reach 2048
- **Character Themes** — sidebar with 14 characters (Eleven, Mike, Will, Dustin, Lucas, Max, Steve, Nancy, Joyce, Hopper, Robin, Eddie, Vecna, Mind Flayer). Clicking changes the accent colors, Christmas lights, and background image to each character's iconic moment
- **Demogorgon** — a CSS-animated Demogorgon face that appears at score ≥ 32, opens its petals at ≥ 128, and roars when you reach a new high score
- **Stranger Things atmosphere** — Upside Down floating particles (canvas), vine overlays, dark red palette, CRT scanlines, Christmas lights inspired by the alphabet wall
- **Mobile support** — touch/swipe controls + on-screen D-pad
- **Timer** — tracks your play time per game

## Tech Stack

- Vanilla JavaScript (ES6+)
- CSS3 (Grid, Custom Properties, Animations, Gradients)
- HTML5
- Canvas (particle system)

## Controls

| Input | Action |
|-------|--------|
| Arrow keys | Move tiles |
| Swipe | Move tiles (mobile) |
| D-pad buttons | Move tiles |
| Start / Restart | New game |
